# 첫 화면과 입력 동선 개선 · 29~31단계

제작자 요청(2026-11-02): “UX적으로 개선을좀 하는거 동의함 개선 해봐”, “가격비교가 처음 화면에 왔으면 좋을거 같고 그중에서도 사진 비교하는게 메인”. `saving` 브랜치에서 커밋만 하고 push하지 않는다.

## 29단계 · 가격표 사진을 첫 화면으로

1. T1: 주요 탭의 첫 항목과 초기 화면을 가격 비교로 바꾸고, AI 서버 주소가 있으면 가격표 사진을 첫 비교 화면으로 연다. 서버 주소가 없으면 사용 가능한 할인 비교로 연다. 묶음 비교에서 재고 값을 넘긴 경우에는 묶음 비교를 우선한다.
2. T2: 사진 선택 화면을 짧은 그림·핵심 행동 중심으로 정리한다. 개인정보 문구와 기존 사진 읽기·결과·취소 규칙은 유지한다. 360px과 키보드 포커스를 확인한다.

## 30단계 · 장보기 한 번에 고르기

3. T3: 한 끼 드롭다운과 이번 주 요리 버튼을 하나의 최대 3개 선택으로 합친다. 후보마다 부족한 재료의 출처를 정확히 보여 주고, 후보가 생기기 전에는 재고 입력으로 바로 가는 길을 둔다. 체크는 기존처럼 임시 상태다.

## 31단계 · 물건 카드에서 사기 전 확인

4. T4: 고민 카드에서 해당 물건의 사기 전 요약으로 바로 이동·포커스한다. 다른 물건의 카드는 건드리지 않는다.
5. T5: 사기 전 상세의 네 묶음(할부·사용 횟수·대용량·목표가/본 값)을 한 번에 하나씩 열어 적는다. 입력 중 값·오류는 선택을 바꿔도 남긴다.

PRD의 AC를 먼저 테스트로 옮긴다. 단계마다 관련 테스트, 전체 테스트, lint, tsc, 빌드, 폭 360px과 포커스를 확인하고 코드 커밋 뒤 TODO·DEVLOG·GPT 진행기록·화면 확인 목록을 적는다.
