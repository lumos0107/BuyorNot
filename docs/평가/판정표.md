# PRD '제작자 확인 전' 판정표

- 대상: PRD v0.44에서 "Claude 결정, 제작자 확인 전"으로 표시된 결정 40개(PRD 9장 '남은 결정 목록'과 같은 순서). 2026-10-31 평가 1회차 P5에서 30줄로 만들었고, 평가 B 판정 R38로 3줄(31~33)을 더하고 #28을 넓혔으며(F32 첫 줄과 두 확인 상자의 설명 연결), 개발 2회차 전체 리뷰 뒤 판정 R43으로 1줄(34)을 더했다. 2026-11-01 절약·저축 1a(PRD v0.44 F45~F49·F20 보강)로 6줄(35~40)을, 절약·저축 1b(PRD v0.46)로 6줄(41~46)을 더했다
- 쓰는 법: '제작자 판정' 칸에 **예**(그대로), **아니오**(되돌림), **바꿈**(바꿀 내용은 메모에) 중 하나를 적는다. 이 두 칸은 제작자만 쓴다.
- 판정한 뒤: Claude가 PRD를 고친다(updating-prd). 예면 기능 절의 "(Claude 결정, 제작자 확인 전)"을 "(YYYY-MM-DD 제작자 확인)"으로 바꾸고, 아니오·바꿈이면 기능 절·검증 사례를 고친 뒤 코드와 테스트를 맞춘다. 9장의 줄은 지우지 않고 끝에 결과를 적는다.
- 번호(판정)는 구현을 맡긴 총괄의 판정 기록 번호다(원문은 저장소 밖 `.superpowers/sdd/`). R29-P2처럼 붙은 것은 판정 R29(개발 1회차 범위) 안의 평가 항목이다. '—'는 판정 번호 없이 구현이나 리뷰 중에 정한 것이다.
- R29·R30 줄(22~30)은 개발 1회차(TODO 16-1~16-4, 커밋 d97e622·2a47245·cf3ff01·827f376)에서 PRD 문장대로 만들었다. '아니오'·'바꿈'이면 PRD를 먼저 고친 뒤 코드와 테스트도 고친다(updating-prd).
- R38 줄(31~33)과 #28의 넓힌 부분은 개발 2회차(TODO 17-1~17-4, 계획 [2026-10-31-improve-round2.md](../superpowers/plans/2026-10-31-improve-round2.md))에서 PRD v0.38 문장대로 만들었고, R43 줄(34)은 같은 회차 전체 리뷰 뒤 최종 수정(TODO 17-8, `26d33e0`)에서 PRD v0.40 문장대로 만들었다. '아니오'·'바꿈'이면 PRD를 먼저 고친 뒤 코드와 테스트도 고친다.
- 35~40줄(절약·저축 1a)은 아직 만들지 않았다. 계획 [2026-11-01-saving-p1a.md](../superpowers/plans/2026-11-01-saving-p1a.md)(TODO 18단계, 브랜치 `saving`)에서 PRD v0.44 문장대로 만든다. 만들기 전에 '아니오'·'바꿈'이면 PRD를 먼저 고친 뒤 계획을 고친다. 설계 근거는 [설계 문서](../superpowers/specs/2026-11-01-saving-features-design.md)(2026-11-01 GPT 53·빌더 점검 반영 판)이고, 번호 칸의 R45·R46은 그 설계를 고친 총괄 판정이다.
- 정하지 못한 것(마감일, F31 아래 카드 중복, 상품명을 고치면 브랜드를 비울지, 다나와 자동 조회)은 결정이 아니라 질문이라 이 표에 없고 PRD 9장 끝에 있다.

**꼭 볼 줄(시간이 없으면 이 9줄부터):** #1, #2, #3, #5, #15, #27, #30, #31, #32. 고른 기준은 평가 B 교수 평가(8장 제안 1)와 세 관점 토론이다. 앞의 일곱 줄은 문구가 아니라 동작을 정한 줄이다: #1은 모든 사진 기능의 대기 시간, #2·#3은 Gemini에 보내는 요청 모양(정확도 평가 결과에 닿음), #5는 폰에서 카메라·갤러리가 열리는 방식(F44 캡처는 갤러리에서 고름), #15는 사용자의 녹음을 끊는 때, #27·#30은 모든 담기에 닿고 적은 내용을 지킬지 정한다. 새 줄 가운데 #31(서버 실패 구분)은 서버 응답과 평가 채점을 바꾸고 평가용을 처음 돌리기 전에 정해야 해서, #32(회고 한 줄)는 실제 사용자·기능 기획 평가가 함께 1순위로 꼽은 순환의 끝이라서 넣었다(토론 채점 가치·비용 위험). 나머지 줄은 대부분 문구나 채점 세부다. 절약·저축 1a의 새 줄 가운데는 #38(모으기의 세 숫자를 더하지 않는 것)이 기능의 뜻을, #36(체험 뒤 결제일)과 #37(해지한 것을 지우지 않고 따로 둠)이 저장과 계산을 정한다. 판정은 제작자만 한다.
