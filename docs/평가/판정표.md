# PRD '제작자 확인 전' 판정표

- 대상: PRD v0.36에서 "Claude 결정, 제작자 확인 전"으로 표시된 결정 30개(PRD 9장 '남은 결정 목록'과 같은 순서, 2026-10-31 평가 1회차 P5에서 만듦)
- 쓰는 법: '제작자 판정' 칸에 **예**(그대로), **아니오**(되돌림), **바꿈**(바꿀 내용은 메모에) 중 하나를 적는다. 이 두 칸은 제작자만 쓴다.
- 판정한 뒤: Claude가 PRD를 고친다(updating-prd). 예면 기능 절의 "(Claude 결정, 제작자 확인 전)"을 "(YYYY-MM-DD 제작자 확인)"으로 바꾸고, 아니오·바꿈이면 기능 절·검증 사례를 고친 뒤 코드와 테스트를 맞춘다. 9장의 줄은 지우지 않고 끝에 결과를 적는다.
- 번호(판정)는 구현을 맡긴 총괄의 판정 기록 번호다(원문은 저장소 밖 `.superpowers/sdd/`). R29-P2처럼 붙은 것은 판정 R29(개발 1회차 범위) 안의 평가 항목이다. '—'는 판정 번호 없이 구현이나 리뷰 중에 정한 것이다.
- R29·R30 줄(22~30)은 아직 만들지 않은 것이다(TODO 16단계). 만들기 전에 판정하면 바뀐 문장대로 만든다.
- 정하지 못한 것(마감일, F31 아래 카드 중복, 상품명을 고치면 브랜드를 비울지, 다나와 자동 조회)은 결정이 아니라 질문이라 이 표에 없고 PRD 9장 끝에 있다.
