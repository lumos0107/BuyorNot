# 살까말까 시연 순서

발표 자료: [index.html](index.html) (브라우저로 열고 ← → 방향키로 넘긴다)
시연 주소: https://lumos0107.github.io/BuyorNot/ (스마트폰 또는 PC 브라우저의 모바일 보기, 360px)

시연 전에 브라우저의 사이트 데이터를 지워 빈 상태에서 시작한다. 전체 5분 안에 끝낸다. 시간이 모자라면 ★ 표시 단계는 건너뛴다.

## 1. 고민 목록 (1분 20초)

1. 첫 화면에서 **예시 물건 넣기**를 누른다. → 재검토 가능 1개("(예시) 무선 헤드폰"), 고민 중 1개("(예시) 접이식 건조대")가 보인다. 구매 포기·구매함 예시는 결정 기록에 들어간다.
2. 상품명 칸에 **게이밍 키보드**를 입력한다. → 폼 아래 "3일 전에 '(예시) 게이밍 키보드'를 구매 포기했어요". 입력을 지운다.
3. "(예시) 무선 헤드폰" 카드에서 **처음 적은 이유**, "아직 필요한가요?", **비교해 볼 곳**(상품명 검색, 추천 아님, 새 창)을 보여준다.
4. ★ "(예시) 접이식 건조대" 카드에서 **더 고민하기 → 3일 더**를 누른다. → "10일 고민 · 1번 연장".
5. 헤드폰 카드에서 **구매 포기**를 누르고 메모에 "쓰던 유선 이어폰을 고쳐 씀"을 적은 뒤 **구매 포기 확인**. → 카드가 사라진다.

말할 것: "고민 중에도 결정할 수 있어요. 기간이 지나면 재검토 가능 표시만 바뀌고, 구매·포기는 직접 골라요. 비슷한 물건을 전에 포기했다면 알려 줘요."

## 2. 결정 기록 (50초)

1. **결정 기록** 메뉴 → 요약 "구매 포기 2건 278,000원"(예시 키보드 + 방금 포기한 헤드폰)과 "실제로 아낀 돈과는 다를 수 있어요" 안내를 보여준다.
2. 시급 칸에 **10000**을 넣는다. → "입력한 시급으로 환산하면 약 27.8시간".
3. "(예시) 무선 청소기"(9일 전 구매) 카드의 "잘 샀나요?"에서 **그저 그래요 → 회고 저장**. → 요약에 "회고 1건 중 후회 0건".
4. ★ 필터 **구매 포기 (2)**를 누른다. → 포기 기록 2개, 헤드폰 카드에 방금 쓴 결정 메모.
5. 새로고침한다. → 기록이 그대로 남아 있다. (localStorage)

말할 것: "구매 포기 금액은 담을 때 적은 가격의 합이라 절약액이라고 부르지 않아요. 산 물건은 일주일 뒤에 잘 샀는지 물어요."

## 3. 할인 비교 (40초)

1. **가격 비교** 메뉴 → 할인 비교 탭에서 **예시 넣기**를 누른다.
2. 결과: A안 73,000원, B안 72,000원, "B안이 1,000원 저렴해요".
3. 계산 근거를 읽는다: 80,000 × 15% = 12,000 → 최대 할인 10,000 적용 → 80,000 − 10,000 + 3,000.
4. ★ A안의 **최소 주문액**에 100000을 넣는다. → "쿠폰 적용 불가 · 최소 주문액까지 20,000원 부족", 결제액 83,000원.

말할 것: "할인율은 0.01% 단위 정수로 계산해서 9,900원 × 41%가 4,058원이 아니라 4,059원으로 정확히 나와요."

## 4. 묶음상품 비교 (30초)

1. 묶음상품 비교 탭에서 **예시 넣기**를 누른다.
2. 결과: 100mL당 333.33원 vs 360.00원, "상품 A가 단가 7.4% 낮아요", "총지출은 상품 A가 600원 더 커요".
3. ★ 상품 B의 단위를 **g**으로 바꾼다. → "부피와 무게는 비교할 수 없어요".

## 5. 무료배송 채우기 (30초)

1. 무료배송 채우기 탭에서 **예시 넣기**를 누른다.
2. 결과: 지금 30,000원 → 추가한 뒤 35,000원, 총지출 차이 +5,000원, "배송비 3,000원 줄고 총지출 5,000원 늘어요".

말할 것: "단가가 낮다고, 무료배송이 된다고 사라고 하지 않아요. 총지출을 같이 보여주고, 필요한지는 직접 판단하라고 적어 둬요."

## 6. 구독 (40초)

1. **구독** 메뉴 → **예시 구독 넣기**를 누른다.
2. 요약: 월 34,400원, 연 412,800원, "해지 후보 1개 · 월 10,900원".
3. "(예시) 음악 스트리밍" 카드: "해지 후보", "사용 기록 없음", 다음 결제 D-n. 목록은 결제일이 가까운 순서다.

말할 것: "알림은 보내지 않고, 화면에서 다음 결제일과 오래 안 쓴 구독을 보여줘요."

## 7. 마무리 (20초)

- GitHub 저장소의 커밋 목록과 Actions 배포 기록을 한 번 보여준다.
- DEVLOG의 "총지출 방향 버그"와 "AC27 계획서 모순"(11단계) 항목을 가리킨다.

## 막혔을 때

- 배포 링크가 안 열리면: `npm run build && npm run preview` 후 http://localhost:4173/BuyorNot/
- 예시 데이터가 이미 있으면: 카드의 **삭제 → 지우기**로 지우거나 브라우저 사이트 데이터 삭제
- 화면이 PC 폭이면: 개발자 도구(F12) → 기기 툴바에서 360px로
- 날짜에 따라 D-n과 "n일 전"은 달라진다. 예시 데이터는 넣는 날을 기준으로 만들어지므로 순서와 상태는 같다.
