# 살까말까 시연 순서

발표 자료: [index.html](index.html) (브라우저로 열고 ← → 방향키로 넘긴다)
시연 주소: https://lumos0107.github.io/BuyorNot/ (스마트폰 또는 PC 브라우저의 모바일 보기, 360px)

시연 전에 브라우저의 사이트 데이터를 지워 빈 상태에서 시작한다. 전체 6분 안에 끝낸다. 시간이 모자라면 ★ 표시 단계는 건너뛴다.

## 1. 고민 목록 (1분 40초)

1. 첫 화면에서 **예시 물건 넣기**를 누른다. → 재검토 가능 1개("(예시) 무선 헤드폰"), 고민 중 1개("(예시) 접이식 건조대")가 보인다. 구매 포기·구매함 예시는 결정 기록에 들어간다.
2. 상품명 칸에 **게이밍 키보드**를 입력한다. → 폼 아래 "3일 전에 '(예시) 게이밍 키보드'를 구매 포기했어요". 입력을 지운다.
3. "(예시) 무선 헤드폰" 카드에서 처음 적은 이유와 담을 때 답한 것(지금 쓰는 게 있어요 · 한 달 뒤에도 쓸지: 모르겠어요), **비교해 볼 곳**(상품명 검색, 추천 아님)을 보여준다.
4. 헤드폰 카드에서 **구매함**을 누른다. → "사기 전에 한 번 더 · 걸리는 점 2개"와 "한 번 생각해 볼 질문". **취소**한다.
5. **구매 포기**를 누르고 메모에 "쓰던 유선 이어폰을 고쳐 씀"을 적은 뒤 **구매 포기 확인**. → 제목 아래 "‘(예시) 무선 헤드폰’을 구매 포기로 옮겼어요. 되돌리기".
6. ★ **되돌리기**를 누르면 카드가 돌아온다. 다시 구매 포기한다.

말할 것: "사려고 할 때 '충동구매예요'라고 단정하지 않고, 내 기록에서 찾은 근거만 보여줘요. 답하지 않은 질문은 걸리는 점으로 세지 않고 생각해 볼 질문으로 따로 보여줘요."

## 2. 결정 기록 (50초)

1. **결정 기록** 메뉴 → 요약 "구매 포기 2건 278,000원"과 "실제로 아낀 돈과는 다를 수 있어요" 안내를 보여준다.
2. 시급 칸에 **10000**을 넣는다. → "입력한 시급으로 환산하면 약 27.8시간".
3. "(예시) 무선 청소기"(9일 전 구매) 카드의 "잘 샀나요?"에서 **그저 그래요 → 회고 저장**. → 요약에 "회고 1건 중 후회 0건".
4. ★ 같은 카드의 **다시 고민하기**를 보여 주고 취소한다(잘못 결정한 기록을 되돌리는 기능).

## 3. 할인 비교 (40초)

1. **가격 비교** 메뉴 → 할인 비교 탭에서 **예시 넣기**를 누른다.
2. 결과: A안 73,000원, B안 72,000원, "B안이 1,000원 저렴해요". 계산 근거를 읽는다.
3. ★ **B안으로 담기**를 누른다. → 고민 중인 물건으로 넘어가 가격 72000과 이유 "가격 비교: B안 결제액 72,000원 (할인 8,000원 · 배송비 포함)"이 채워지고 상품명에 커서가 간다. 다시 가격 비교로 돌아온다.

말할 것: "할인율은 0.01% 단위 정수로 계산해서 9,900원 × 41%가 4,058원이 아니라 4,059원으로 정확히 나와요."

## 4. 묶음상품 비교 (30초)

1. 묶음상품 비교 탭에서 **예시 넣기**를 누른다.
2. 결과: 100mL당 333.33원 vs 360.00원, "상품 A가 단가 7.4% 낮아요", "단가는 상품 A가 낮지만, 총지출은 상품 B가 600원 적어요".

## 5. 무료배송 채우기 (30초)

1. 무료배송 채우기 탭에서 **예시 넣기**를 누른다.
2. 결과: 지금 30,000원 → 추가한 뒤 35,000원, 총지출 차이 +5,000원, "배송비 3,000원 줄고 총지출 5,000원 늘어요".

말할 것: "단가가 낮다고, 무료배송이 된다고 사라고 하지 않아요. 총지출을 같이 보여주고, 필요한지는 직접 판단하라고 적어 둬요."

## 6. 구독 (1분)

1. **구독** 메뉴 → **예시 구독 넣기**를 누른다.
2. 요약: 월 46,280원, 연 555,360원, "해지 후보 1개 · 월 10,900원".
3. "(예시) 쿠팡 와우 멤버십" 카드: "사용량(예시): 최근 30일 1번 사용 · 1번에 약 7,890원". 최근에 써서 해지 후보는 아니지만 한 번에 드는 돈이 크다.
4. "(예시) 음악 스트리밍" 카드의 **오늘 썼어요**를 누른다. → 마지막 사용이 오늘이 되고 해지 후보에서 빠지며 "사용량(직접 기록)"으로 바뀐다.

말할 것: "웹사이트는 휴대폰의 스크린 타임을 읽을 수 없어서, 지금은 직접 기록하고 예시 구독에만 예시 숫자를 보여줘요. 휴대폰 앱으로 만들면 안드로이드는 사용 시간을 가져올 수 있고, 아이폰은 제약이 커요."

## 7. 마무리 (30초)

- ★ 화면 맨 아래 **기록 백업·복원**을 펼쳐 백업 파일 받기를 보여준다(서버 없이 기록을 옮기는 방법).
- GitHub 저장소의 커밋 목록과 Actions 배포 기록을 한 번 보여준다.
- DEVLOG의 "총지출 방향 버그"와 "AC27 계획서 모순"(11단계) 항목을 가리킨다.

## 막혔을 때

- 배포 링크가 안 열리면: `npm run build && npm run preview` 후 http://localhost:4173/BuyorNot/
- 예시 데이터가 이미 있으면: 제목 아래 **예시만 지우기**(구독은 **예시 구독만 지우기**)로 지우거나 브라우저 사이트 데이터 삭제
- 화면이 PC 폭이면: 개발자 도구(F12) → 기기 툴바에서 360px로
- 날짜에 따라 D-n과 "n일 전"은 달라진다. 예시 데이터는 넣는 날을 기준으로 만들어지므로 순서와 상태는 같다.
