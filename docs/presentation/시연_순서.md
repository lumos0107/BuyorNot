# 살까말까 시연 순서

발표 자료: [index.html](index.html) (브라우저로 열고 ← → 방향키로 넘긴다)
시연 주소: https://lumos0107.github.io/BuyorNot/ (스마트폰 또는 PC 브라우저의 모바일 보기, 360px)

시연 전에 브라우저의 사이트 데이터를 지워 빈 상태에서 시작한다. 전체 3분 안에 끝낸다.

## 1. 숙려 리스트 (1분)

1. 첫 화면에서 **예시 물건 넣기**를 누른다. → 재검토 가능 1개, 숙려 중 1개가 보인다.
2. "(예시) 무선 헤드폰" 카드에서 **처음 적은 이유**와 "아직 필요한가요?"를 보여준다.
3. **구매 포기**를 누른다. → 카드가 사라진다.
4. **결정 기록** 메뉴로 가서 "구매 포기" 기록 2개(예시 키보드 + 방금 포기한 헤드폰)를 보여준다.
5. 새로고침한다. → 기록이 그대로 남아 있다. (localStorage)

말할 것: "숙려 중에도 결정할 수 있어요. 기간이 지나면 재검토 가능 표시만 바뀌고, 구매·포기는 직접 골라요. 이 브라우저에만 저장돼요."

## 2. 할인 비교 (1분)

1. **가격 비교** 메뉴 → 할인 비교 탭에서 **예시 넣기**를 누른다.
2. 결과: A안 73,000원, B안 72,000원, "B안이 1,000원 저렴해요".
3. 계산 근거를 읽는다: 80,000 × 15% = 12,000 → 최대 할인 10,000 적용 → 80,000 − 10,000 + 3,000.
4. A안의 **최소 주문액**에 100000을 넣는다. → "쿠폰 적용 불가 · 최소 주문액까지 20,000원 부족", 결제액 83,000원.
5. **할인율**에 120을 넣는다. → 입력 아래 오류, 결과는 숨겨진다.

말할 것: "할인율은 0.01% 단위 정수로 계산해서 9,900원 × 41%가 4,058원이 아니라 4,059원으로 정확히 나와요."

## 3. 묶음상품 비교 (40초)

1. 묶음상품 비교 탭에서 **예시 넣기**를 누른다.
2. 결과: 100mL당 333.33원 vs 360.00원, "상품 A가 단가 7.4% 낮아요", "총지출은 상품 A가 600원 더 커요".
3. 상품 B의 단위를 **g**으로 바꾼다. → "부피와 무게는 비교할 수 없어요".

말할 것: "단가가 낮다고 사라고 하지 않아요. 총지출을 같이 보여주고, 가격만 비교한 결과라고 적어 둬요."

## 4. 마무리 (20초)

- GitHub 저장소의 커밋 목록과 Actions 배포 기록을 한 번 보여준다.
- DEVLOG의 "총지출 방향 버그"와 "Infinity 크래시" 항목을 가리킨다.

## 막혔을 때

- 배포 링크가 안 열리면: `npm run build && npm run preview` 후 http://localhost:4173/BuyorNot/
- 예시 데이터가 이미 있으면: 카드의 **삭제 → 지우기**로 지우거나 브라우저 사이트 데이터 삭제
- 화면이 PC 폭이면: 개발자 도구(F12) → 기기 툴바에서 360px로
