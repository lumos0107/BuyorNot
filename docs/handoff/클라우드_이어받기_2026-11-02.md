## 이어서 다듬을 때

1. 실제 공개 사이트와 README 사진을 나란히 보며 크기·비율·문구를 다시 확인한다. 사진 예시에는 저장된 값과 과거 다나와 가격임을 계속 명확하게 표시한다.
2. README는 1차 과제와 중간 과제 사이의 **추가·개선 기능과 전후 사진**을 읽기 쉽게 보여 주고, 상세 요구사항·변경 이력은 PRD와 TODO에 둔다. 과제 제출에 필요한 스킬 사용·느낀 점·결론은 유지한다.
3. 공개 AI 연결 문제는 별도 미완료 과제다. 해결 전까지 실시간 사진·음성·다나와 조회가 된다고 설명하거나 검증되지 않은 정확도를 주장하지 않는다. 가격·상품 규격이 바뀔 수 있으므로 저장된 다나와 가격을 현재 최저가로 부르지 않는다.
4. 코드나 문서를 바꾸면 `saving`과 `main`의 업로드 및 GitHub Actions 결과를 확인한다. 사용자와 합의한 작업 범위 밖의 비밀값·개인 기록은 올리지 않는다.

## Git에서 의도적으로 제외한 로컬 자료

`worker/.dev.vars`의 Gemini 키, `.wrangler/` 캐시, `node_modules/`, `dist/`, 개인 기록과 방대한 과거 리뷰 임시 파일은 Git에 없다. 대신 [.superpowers/sdd/saving/](../../.superpowers/sdd/saving/)의 원래 GPT 인계·진행기록·결정·화면 확인 문서 15개는 Git에 추가했다. 오래된 인계 문서가 가리키는 `saving/` 문서는 클라우드에서도 열 수 있다. 클라우드 작업에 필요한 현재 요구사항·완료 상태·화면·코드는 위에 링크한 **추적 파일**에 있다.
