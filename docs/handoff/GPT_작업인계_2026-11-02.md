# GPT → Claude 작업 인계와 다른 컴퓨터 이동 초안

작성일: 2026-11-02 · 상태: **Claude 검토 전** · 저장소: 살까말까 · 브랜치: `saving`

이 문서는 Claude가 2026-11-01에 넘긴 [원래 인계](../../.superpowers/sdd/saving/GPT_인계.md) 이후 GPT가 한 일을 모은다. 원래 인계와 이 문서의 `.superpowers/sdd` 링크는 Git에서 제외된 로컬 파일이므로, 다른 컴퓨터에는 이동 묶음의 `notes/`도 함께 복사해야 열린다. 제작자 지시대로 **push·병합·배포는 하지 않았다.**

## 2. 제작자가 GPT에게 준 방향

1. [원래 인계](../../.superpowers/sdd/saving/GPT_인계.md)의 1b부터 이어 개발하고, 단계마다 [GPT 진행기록](../../.superpowers/sdd/saving/GPT_진행기록.md)과 화면 확인 목록을 남긴다. push하지 않는다.
2. 20~30대 자취생의 절약이 중심이다. 불필요한 구매를 줄이고 필요한 구매는 더 낮은 실제 지출로 판단하도록 돕는다. 입력은 쉽게, 글과 구분 상자는 줄이고, 그림과 일관된 디자인을 쓴다. 담기 항목은 접고 펼칠 수 있게 한다.
3. 1b~4단계 뒤 추가한 ‘오늘 확인할 것·빠른 담기’, ‘30일 결제 달력·장보기 초안’ 두 기능을 구현했다. 새 스킬 [simplifying-entry-flows](../../.claude/skills/simplifying-entry-flows/SKILL.md)을 만들어 적용했다.
4. 다시 합의한 여섯 기능(이번 주 집밥, 정기배송 중복 확인, 한 주 작은 지출 시도, 사기 전 요약, 결제 전 확인, 상황별 시작)을 모두 구현했다. 한 주 시도는 최종 대조에서 선택·저장 흐름을 추가 보강했다.
5. 마지막 요청은 **가격 비교가 첫 화면, AI 서버가 있으면 가격표 사진이 그 안의 첫 화면**이라는 UX 변경이다. 개발 도중 제작자가 “잠깐 멈춰줘”라고 해 중단했다. **이 변경은 완료로 보고하지 않는다.**

## 4. GPT가 직접 확인한 사진 가격 비교

- 2026-11-02에 준비된 라면 가격표 사진 한 장을 실제 Gemini와 임시 Worker에 보냈다. 상품명·매장 가격 3,980원을 읽었고, 다나와 자동 조회를 임시로 켠 서버에서 6개 묶음 표시가 4,900원인 줄을 골라 **표시 가격 차이 920원**을 화면에서 계산했다. Worker 로그에서 사진 읽기·온라인 조회가 각각 200으로 확인됐다.
- 공유 로컬 서버 `:8787`은 한때 요청에 응답하지 않아 재시작했다. 기본 설정은 `DANAWA_ENABLED=false`; 재시작 뒤 사진 읽기는 200, 온라인 확인은 `off`로 돌아와 다나와 검색 링크만 보였다. **현재 기본 설정에서 자동 온라인 가격 비교가 켜진 것은 아니다.**
- 실제 사진 여러 장의 상품·규격 일치율과 배송비 포함 결제액은 평가하지 않았다. 과거 [AI 정확도 평가 기록](../ai-eval.md)도 확인한다. 이 시험에서 저장소 파일은 고치지 않았다.

## 7. 다른 컴퓨터로 옮길 것

이 저장소를 GitHub에서 다시 clone하는 것만으로는 로컬 3개 브랜치의 앞선 커밋, 중단된 작업 트리, Git 제외 기록이 빠진다. 이동 묶음에는 다음을 넣는다.

1. `BuyorNot-branches.bundle`: 로컬 `saving`·`ai-stage1`·`main`의 **커밋과 이력**.
2. `paused-ux.patch`: 현재 추적 파일의 **미커밋 변경**. 중단된 UX 작업이므로 먼저 검토하고 적용한다.
3. `untracked/`: 새 계획·시험 파일 두 개.
4. `notes/`: Git 제외된 원래 인계·결정·GPT 진행기록·화면 확인 목록.
5. 이 문서와 커밋 목록. 브라우저 `localStorage`의 실제 기록이 필요하면 앱의 **기록 백업·복원**에서 별도 파일로 내려받아 개인적으로 옮긴다.

`node_modules/`, `dist/`, `_개인기록/`, `worker/.dev.vars`는 이동 묶음에 넣지 않는다. AI 키는 다른 컴퓨터에서 안전한 방법으로 다시 설정한다. 다른 컴퓨터에서는 `npm ci`로 의존성을 설치한다. 개발 서버·로컬 Worker는 파일이 아니라 다시 실행할 프로그램이다.

## 8. 남은 결정과 제한

- 현재 작업 트리에는 제작자가 요청한 사진 중심 첫 화면 변경이 중단된 채 남아 있다. 완성·커밋·push하지 않았다.
- 1b~28단계의 코드 시험과 PC 브라우저 360px 확인이 실제 스마트폰·실사용 절약 효과를 증명하지는 않는다. [README](../../README.md)의 효과 한계를 따른다.
- AI 서버 배포, 실제 자료 정확도 평가, 다나와 자동 조회를 켤지, 판정표의 제작자 칸, 학생 서술 칸은 제작자 결정·작업으로 남는다([TODO](../../TODO.md) “남은 일”).
- Claude 검토 결과가 이 문서와 다르면 **차이를 기록하고 현재 코드·실행 결과를 기준으로 수정**한다. 이 문서의 검토 전 표를 완료로 바꾸는 일은 Claude가 실제 점검한 뒤에만 한다.
