# PRD 고치기

## 개요

PRD.md는 기능 번호(Fnn)·검증 사례(ACnn)·버전이 여러 곳에서 서로를 가리킨다. 한 곳만 고치면 어긋난다. 변경 종류에 맞는 목록을 따라가고, 번호 참조는 스크립트로, 내용과 출처가 맞는지는 사람이 본다.

**확정과 미확정을 나눈다.** 제작자가 승인한 것만 명세에 쓴다. 승인 전 제안은 기능 절에 쓰지 않고 9장 "남은 결정"이나 별도 문서에 둔다. GPT 상의에서 나온 의견도 제작자가 받아들이기 전에는 제안이다.

## 변경 종류별 목록

**공통(모든 변경)**
1. 머리말 `버전:` 줄: 소수 둘째 자리를 하나 올리고 맨 앞에 `0.NN · {바뀐 것}({날짜}, {출처})`.
2. 끝나면 `python .claude/skills/updating-prd/scripts/check_prd_refs.py PRD.md` → `OK`까지. '확인할 것'은 한 입력에 결과가 여럿인 행이나 이번 변경 밖의 옛 행이면 그대로 둔다.
3. 이어서 TODO 반영(todo-sync). 커밋만, push는 제작자.

**새 기능**
- 번호: PRD에 나온 가장 큰 F 다음(2·3단계 계획 표에 자리만 잡힌 번호 포함, 빈 번호 재사용 금지). AC는 표의 마지막 다음.
- 한눈에 보기: "4. 꼭 있어야 하는 기능"에 한 문장(필요할 때), "기능 번호와 검증 사례:" 줄에 `Fnn(ACaa~ACbb)`. 3장 범위 표의 해당 행.
- 기능 절 `### Fnn 이름 ({날짜} {출처})`를 비슷한 기능 뒤, "2·3단계 계획" 앞에. 내용: 목적, 위치, 흐름, 화면 문장(따옴표 안 그대로 쓸 문장), 하지 않는 것, 마지막 줄 `- 완료 기준: ACaa~ACbb.` 기록을 저장하는 기능이면 저장(선택 필드·schemaVersion·손상 처리·백업·여러 탭)도.
- 이 기능이 건드리는 기존 절 끝에 `- {날짜} Fnn(이름)로 보강: …` 한 줄.
- 11장 제목 범위와 표 끝의 새 행. 행마다 입력과 기대 결과를 ` / `로 같은 순서·같은 개수로 나누고, 화면 문장은 따옴표 안에 그대로.

**기존 기능 고치기·빼기**
- 그 기능 절의 문장을 고치고, 고친 줄 끝에 `({날짜} {출처}: 전 → 후)`처럼 무엇이 바뀌었는지 남긴다. 뺀 내용은 지우지 말고 `({날짜} 뺌, 이유)`로 남긴다.
- 그 문장을 쓰는 AC 행의 기대 결과도 같이 고친다. 다른 절(F15 등)이 그 기능을 가리키면 그곳도.

**결정 바꾸기·남은 결정 풀기**
- 9장 "남은 결정"에서 지우거나 결과를 적고, 그 결정을 쓴 기능 절의 `(Claude 결정, 제작자 확인 전)` 표시를 출처로 바꾼다.

## 출처 표기

| 누가 정했나 | 쓰는 법 |
| --- | --- |
| 제작자 요청 | `2026-10-30 제작자 요청 "요청 원문"` |
| GPT 상의 의견을 제작자가 받아들임 | `GPT 42번 합의` 또는 `(GPT 42번)` |
| Claude가 정하고 제작자 확인 전 | 문장 끝 `(Claude 결정, 제작자 확인 전)` + 9장 "남은 결정"에 한 줄 |
| 정하지 못함 | 기능 절 안 "남은 결정:"과 9장에 질문으로 |

날짜는 실제 날짜 `YYYY-MM-DD`. 출처는 실제 기록(대화의 요청 원문, GPT_검토_기록의 번호)에서 옮기고 지어내지 않는다.

## 스크립트가 보는 것과 못 보는 것

보는 것: 버전 줄(HEAD의 PRD보다 올랐는지), F 제목 중복, AC 중복·빠진 번호, 11장 제목 범위, 완료 기준이 가리키는 AC가 표에 있는지, 어느 완료 기준에도 안 걸린 AC(F31 이후), 한눈에 보기 줄의 마지막 F·AC, F31 이후 절의 완료 기준 줄, 입력·결과 개수, CR.
못 보는 것: 내용이 맞는지, 출처가 사실인지, 화면 문장과 AC가 같은 말인지 → 사람이 본다.

## 자주 하는 실수

- 기능 절만 쓰고 버전 줄·한눈에 보기·11장 제목을 빠뜨린다 → 스크립트가 잡는다.
- 화면 문장을 따옴표 없이 풀어 쓴다 → 구현과 테스트가 복사할 수 없다.
- 이전부터 어긋난 다른 곳(예: 9장의 옛 AC 범위)을 말없이 고친다 → 이번 변경 밖이면 그대로 두고 보고에 적는다.
