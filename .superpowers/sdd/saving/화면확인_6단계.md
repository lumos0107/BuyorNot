# 30일 결제 달력·장보기 초안 화면 확인 (2026-11-02)

로컬 `saving` 브랜치에서 약 5~10분 확인한다. 이미 적은 기록이 필요하면 먼저 백업 파일을 받는다. 제작자 판정은 [판정표](../../../docs/평가/판정표.md) #70~#71에 적는다.

| 순서 | 화면에서 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 폭 360px에서 고정비 탭의 ‘앞으로 30일 결제 달력’을 펼친다 | 접힌 줄에 예정 건수와 적어 둔 요금 합계가 보인다. 일곱 열 날짜와 목록을 펼쳐도 가로 스크롤이 없다. |
| 2 | 매월 1일 10,000원과 주마다 4,000원 고정비를 적고 달력을 다시 본다 | 오늘부터 30일에 걸치는 매월 결제와 주마다 결제가 각각 한 건으로 보인다. 월평균이 아닌 실제 적은 주기 요금을 건마다 더한다. |
| 3 | 날짜에 표시가 있는 날을 누르고, 해지한 고정비·무료 체험 중인 고정비도 살펴본다 | 해당 날짜의 목록으로 포커스가 간다. 해지는 빠지고 체험 끝나는 날은 기존 첫 결제일 규칙으로 보인다. |
| 4 | 물건 탭 ‘집에 있는 것’에 세제(조금)·휴지(떨어짐)·쌀(넉넉)을 적은 뒤 ‘장보기 초안’을 연다 | 세제·휴지만 한 번씩 보이고 가격 합계는 없다. |
| 5 | ‘김치두부’ 요리를 두부·김치·계란 재료로 적고 두부는 넉넉·계란은 떨어짐으로 둔 뒤 요리를 고른다 | 김치·계란이 더해지고 계란은 중복 없이 한 줄이다. |
| 6 | 세제를 체크하고 초안을 접었다 다시 연 뒤 새로고침한다 | 같은 화면에서는 체크가 남고 새로고침 뒤에는 사라진다. 세제의 남은 정도·산 값 기록은 바뀌지 않는다. |
| 7 | 기록 백업 파일을 받는다 | 새 저장 키 없이 기존 고정비·집에 있는 것 기록이 들어간다. 달력과 장보기 체크 자체는 백업에 들어가지 않는다. |

자동 테스트 1,965개, lint·타입·커밋 전 검사와 빌드가 통과했다. 브라우저 CSS 폭 360px에서 문서 너비는 350px이었다. 실제 스마트폰과 판정표는 제작자 확인을 기다린다.
