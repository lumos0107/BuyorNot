# 사용 흐름 개선 화면 확인 (2026-11-02)

로컬 `saving` 브랜치에서 약 5~10분 확인한다. 이미 적은 기록이 필요하면 먼저 백업 파일을 받는다. 제작자 판정은 [판정표](../../../docs/평가/판정표.md) #68~#69에 적는다.

| 순서 | 화면에서 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 폭 360px에서 물건 탭을 연다 | ‘오늘 확인할 것’이 보인다. 해당 기록이 없으면 한 줄 안내만 있고 별도 카드 테두리가 늘어나지 않는다. 가로 스크롤이 없다. |
| 2 | ‘물건 담기’를 누르고 ‘전기 포트’·59,000원만 적어 담는다 | 이름·가격과 ‘3일 뒤 다시 볼게요. 이유는 담은 뒤 적어도 돼요.’가 먼저 보인다. 담긴 카드에는 ‘사고 싶은 이유를 아직 적지 않았어요.’가 보이고, 담은 안내는 폼을 접어도 보인다. |
| 3 | 방금 담은 카드의 ‘수정’에서 이유 ‘차를 끓이려고’를 적는다 | 이유가 저장되고 카드에 표시된다. 담기 폼의 값은 새 담기를 위해 비워져 있다. |
| 4 | 다시 물건 담기를 열고 ‘더 적기 (선택)’에서 7일·이유·상품 링크를 적어 담는다 | 상세 값이 저장된다. ‘더 적기’를 접었다 다시 열어도 작성 중이던 값은 남는다. |
| 5 | 예시 물건 넣기 또는 가격 비교에서 담기를 사용한다 | 담기 폼과 ‘더 적기’가 열려 가져온 이유·기간·링크가 보이고 첫 입력으로 포커스가 간다. |
| 6 | 고민 기간이 끝난 물건, 7일 안에 결제할 고정비, 반품 기한, 포인트·쿠폰 만료 기록을 만든 뒤 물건 탭을 다시 본다 | ‘오늘 확인할 것’에 해당 범주만 나타난다. 각 보기를 누르면 원래 탭의 첫 카드가 열리고 포커스가 간다. 해지·반품 완료·지난 만료 기록은 세지 않는다. |
| 7 | 백업 파일을 받아 다시 불러온다 | 이유를 아직 적지 않은 물건도 그대로 읽힌다. 이유 없는 물건의 캘린더 파일에는 빈 ‘처음 적은 이유’ 줄이 없다. |

자동 테스트 1,952개, lint·타입·커밋 전 검사와 빌드가 통과했다. CSS 폭 360px에서 문서 너비는 350px이었다. 실제 스마트폰과 판정표는 제작자 확인을 기다린다.
