# 작은 지출·사기 전 요약 화면 확인 (2026-11-02)

로컬 `saving` 브랜치에서 확인한다. 기존 기록을 지우기 전에는 백업을 받는다. 실제 스마트폰 확인은 제작자 몫이다.

| 순서 | 화면에서 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 모으기 → 자잘한 지출에서 커피 버튼을 만들고, 이전 7일에 ‘썼어요’ 두 건과 최근 7일 한 건이 있는 기록을 본다 | 커피 카드에 “직전 7일 2번 · 최근 7일 1번 · 이번에는 1번까지 시도해 보세요.”가 보인다. 기록된 횟수만 비교한다. |
| 2 | ‘참았어요’를 누르거나 이전 7일에 쓴 기록이 없는 버튼을 본다 | ‘참았어요’는 쓴 횟수에 더하지 않는다. 이전 7일이 0번이면 한 번 덜 쓰기 목표를 만들지 않는다. |
| 3 | 물건 하나에 할부 총액·연간 사용 횟수·목표가를 적고 ‘사기 전에’를 연다 | 카드 위 ‘한눈에 확인’에 일시불·할부 총액·횟수·목표가 등 적힌 근거만 보인다. 사라·말라는 문구가 없다. |
| 4 | ‘자세히 확인·적기’를 열어 총량 입력을 시작하고 접었다 다시 연다 | 입력 중인 값이 남는다. 저장 오류는 펼친 입력에서 확인할 수 있다. |
| 5 | 폭 360px에서 요약과 상세 입력을 본다 | 좌우 스크롤 없이 요약과 버튼을 읽고 누를 수 있다. |

자동 테스트 1,975개, lint·타입·커밋 전 검사·빌드 통과. 브라우저 CSS 폭 360px에서 문서 너비 350px으로 가로 넘침이 없었다.
