# 절약·저축 4단계 화면 확인 (2026-11-02)

로컬 `saving` 브랜치에서 약 5~10분 확인한다. 이미 적은 기록이 필요하면 먼저 백업 파일을 받는다. 제작자 판정은 [판정표](../../../docs/평가/판정표.md) #63~#67에 적는다.

| 순서 | 화면에서 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 폭 360px에서 모으기 탭 맨 아래 ‘받을 수 있는 돈’을 누른다 | 처음에는 접혀 있고 누르면 세 제도·카드 실적·포인트·쿠폰·친구 정산 제목이 보인다. 가로 스크롤이 없다. 사이트 제목과 접이식 카드의 펼침 표식이 같은 색·모양 계열이다. |
| 2 | ‘청년 월세 지원’·‘에너지바우처’·‘교통비 환급’을 각각 열어 공식 안내 링크를 눌러 본다 | 공식 페이지가 새 창으로 열리고 앱에서 적은 이름·금액은 주소에 붙지 않는다. 자격을 판단하는 결과는 없다. |
| 3 | 에너지바우처에 확인한 날·‘신청함’을 저장한 뒤 ‘받는 중’·받은 금액 100,000원을 적는다 | 확인일·상태가 남고, 모으기의 ‘생긴 돈’에 100,000원이 따로 보인다. 실제 옮긴 돈·저축 목표에는 더해지지 않는다. |
| 4 | 카드 실적에서 해당 월 2026-11, 기준 300,000원·쓴 금액 280,000원을 적고 수정에서 2026-10으로 바꾼다 | ‘실적까지 20,000원’과 지난달 ‘2026-10 기록’이 보인다. 혜택 금액을 적어도 생긴 돈에 더해지지 않는다. |
| 5 | 포인트 만료일 11/15와 쿠폰 만료일 11/10을 적고 쿠폰의 캘린더 파일을 받는다 | 11/10이 먼저 보이고 D-n이 표시된다. 종일 일정 파일이 내려받아지며 자동 알림 요청은 없다. |
| 6 | 친구A에게 받을 돈 20,000원, 친구B에게 줄 돈 8,000원을 적고 친구A에 ‘받았어요’를 누른다 | 미정산 합계가 받을 돈 20,000원·줄 돈 8,000원에서 받을 돈 0원·줄 돈 8,000원으로 바뀐다. 받은 돈은 모으기에 더해지지 않고, 별명 백업 안내가 보인다. |
| 7 | 백업 파일을 받아 다시 불러온 뒤, benefits 부분이 없는 기존 판 3 백업도 골라 본다 | 새 백업은 지원 제도·카드·만료·정산 기록을 복원한다. 옛 판 3에서는 받을 수 있는 돈 기록을 현재대로 유지한다고 확인 아래 알린다. |

자동 테스트 1,938개, lint·타입·커밋 전 검사와 빌드가 통과했다. 브라우저 CSS 폭 360px에서 문서 너비는 350px이었다. 실제 스마트폰과 판정표는 제작자 확인을 기다린다.
