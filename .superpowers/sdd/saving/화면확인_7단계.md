# 집밥 계획·정기배송 화면 확인 (2026-11-02)

로컬 `saving` 브랜치에서 확인한다. 기존 기록을 지우기 전에는 백업을 받는다. 실제 스마트폰 확인은 제작자 몫이다.

| 순서 | 화면에서 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 물건 → 집에 있는 것 → 장보기 초안을 열고 ‘이번 주 해 먹을 것’에서 요리 세 개를 고른다 | 누른 요리 셋이 선택 상태로 보이고 공통으로 부족한 재료는 초안에 한 번만 나타난다. 넉넉한 재료는 더하지 않는다. |
| 2 | 넷째 요리를 누르고, 고른 요리 하나를 다시 누른다 | 넷째는 선택되지 않고 “이번 주에는 3개까지 고를 수 있어요.”가 보인다. 다시 누른 요리는 선택에서 빠진다. |
| 3 | 장보기 초안을 접었다 열고 새로고침한다 | 접었다 열면 선택이 남고, 새로고침 뒤에는 선택이 사라진다. 요리·재고 저장 기록은 그대로다. |
| 4 | 집에 있는 것에 휴지 ‘넉넉’을 적고, 고정비에 같은 이름 정기배송을 7일 안의 결제일로 적는다 | 휴지 카드에 “집에 넉넉해요. (날짜) 정기배송 결제 전에 계속 필요한지 확인해 보세요.”가 보인다. 앱이 배송을 변경하지 않는다. |
| 5 | 휴지를 ‘조금’으로 바꾸거나 정기배송을 해지한다 | 중복 확인 문장이 사라진다. 이름이 일부만 같은 정기배송에도 표시되지 않는다. |
| 6 | 폭 360px 화면에서 장보기 초안과 휴지 카드를 펼친다 | 좌우 스크롤 없이 버튼·문장을 읽고 누를 수 있다. |

자동 테스트 1,970개, lint·타입·커밋 전 검사·빌드가 통과했다. 브라우저 CSS 폭 360px에서 문서 너비 350px으로 가로 넘침이 없었다.
