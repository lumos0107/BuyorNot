# 절약·저축 3단계 화면 확인 (2026-11-02)

로컬 `saving` 브랜치에서 약 5~10분 확인한다. 이미 적은 기록이 필요하면 먼저 백업 파일을 받는다. 제작자 판정은 [판정표](../../../docs/평가/판정표.md) #55~#62에 적는다.

| 순서 | 화면에서 할 일 | 기대 결과 |
| --- | --- | --- |
| 1 | 폭 360px에서 물건·고정비 탭을 열고 각각 ‘물건 담기’·‘고정비 담기’를 누른다 | 두 입력 폼이 처음에는 접혀 있고 누르면 펼쳐진다. 이름을 적고 다시 접었다 열어도 값이 남으며 가로 스크롤이 없다. 빈 상태에는 같은 모양의 그림이 보인다. |
| 2 | 고정비 담기에서 종류 ‘멤버십’을 고르고 ‘쓰는 곳 (선택) · 후보 보기’를 누른 뒤 배달·쇼핑을 체크하고 접는다 | 닫힌 줄에 ‘2개 선택’이 보인다. 다시 열면 두 항목에 체크가 남아 있다. |
| 3 | 300,000원짜리 물건을 담고 물건 카드의 ‘사기 전에’를 열어 할부 12개월·월 30,000원을 적는다 | 총 360,000원과 일시불보다 60,000원 더가 보인다. |
| 4 | 같은 카드에 1년에 2번 사용을 적고 중고 링크를 누른다 | 한 번 쓸 때의 금액과 빌리기·중고 안내가 보인다. 중고 사이트 홈페이지가 새 창으로 열리며 상품명·가격은 주소에 없다. |
| 5 | 집에 있는 것에 ‘세탁 세제’를 적고 같은 이름의 물건을 담는다 | 집에 있는 물건 안내가 담기 폼과 ‘사기 전에’에 보인다. 일부 글자만 같은 다른 이름은 중복으로 잡지 않는다. |
| 6 | 물건 카드에 총량 10·월 사용량 1·유통기한 6개월, 목표가 30,000원과 본 값 34,900원·29,900원을 적는다 | 다 쓰는 데 약 10개월과 유통기한 걸리는 점이 보인다. 마지막으로 본 값과 가장 낮게 본 값이 날짜와 함께 구분된다. |
| 7 | 물건을 구매함으로 옮긴 뒤 결정 기록의 ‘산 뒤에’에서 반품 기한을 14일 뒤로 적고 캘린더 파일을 받는다 | 구매함 카드에 반품 기한·D-14가 보이고 종일 일정 파일이 내려받아진다. |
| 8 | 구매함 물건 하나에는 ‘반품했어요’를, 후회·그저 그래요 회고가 있는 다른 물건에는 되팔기 날짜·판 금액을 적는다 | 구매함 카드에 각 기록이 보인다. 모으기에는 반품했다고 적은 금액과 판 금액이 서로 다른 줄에 보이며 실제 옮긴 돈·저축 목표에 더해지지 않는다. |
| 9 | 기록 백업 파일을 받아 다시 불러온다 | 선택 입력값이 유지되고 판 1·판 2 옛 파일도 읽힌다. |

자동 테스트 1,917개, lint·타입·커밋 전 검사가 통과했다. 브라우저 CSS 폭 360px에서 문서 너비는 350px이었다. 실제 스마트폰과 판정표는 제작자 확인을 기다린다.
